## How to add docs for a new folder

1. Create `README.md` (purpose, key files, status, dependencies).
2. Create `skills.md` (when to use, do/don't, workflow steps).
3. Add a row to this index.
4. Link from the parent tree README table.

Template:

```markdown
# <Folder> README
- Purpose / ownership
- Key files
- Dependencies
- Status: active | thin re-export | migrate-to-feature | placeholder | quarantine

# <Folder> skills.md
- When agent should read this
- Allowed changes / do-not
- Workflow steps
- Related paths
```
